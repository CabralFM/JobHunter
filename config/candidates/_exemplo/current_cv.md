# Cole aqui o CV que está sendo usado hoje (convertido para Markdown/texto).

Ele serve para dois propósitos:
1. calcular o "match com o CV atual" (como um recrutador o leria hoje);
2. servir de referência de formato, tom e layout para os CVs adaptados.

Dica para converter um PDF: `pip install markitdown && markitdown meu_cv.pdf > current_cv.md`
